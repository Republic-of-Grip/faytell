Faytell

A public window for content that was chosen. Anyone with the URL can look. The link is shared only when Thor decides to share it.

The window

Faytell does not fill itself. A page is summoned: the content is chosen, a URL exists, and that is the public act. GitHub is the workshop. These pages are the only glass.

Not a generator

There is no prompt, no commission, no machine that writes because a visitor arrived. Faytell will not invent a subject for you. An empty page is empty on purpose.

The workshop

Contribution happens in the repository. Copy s/example/ to s/<slug>/, replace the empty stage with the chosen content, and push to main. The Pages URL for that path is the publication. Share it when you mean to, and not before.
